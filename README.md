# AuroraStay QnA

Low-code Retrieval-Augmented Generation (RAG) proof of concept for AuroraStay Hotels.

## Repository structure

```text
aurora-stay-qna/
├── backend/
│   ├── app.py
│   ├── rag_utils.py
│   ├── requirements.txt
│   ├── Dockerfile
│   └── faiss_index/
│       ├── index.faiss      # generated by the notebook
│       └── index.pkl        # generated by the notebook
└── frontend/
    ├── app.py
    ├── requirements.txt
    └── Dockerfile
```

## Required Codespaces secrets

Create these in **GitHub Settings → Codespaces → Secrets** and grant this repository access:

- `OPENAI_API_KEY`
- `OPENAI_API_BASE`

The backend also accepts `OPENAI_BASE_URL` as a compatibility fallback, but the course deployment guide uses `OPENAI_API_BASE`.

## Build and run in GitHub Codespaces

### Backend

```bash
cd backend
docker build -t aurora-backend .
docker run --name backend --network host \
  -e OPENAI_API_KEY="$OPENAI_API_KEY" \
  -e OPENAI_API_BASE="$OPENAI_API_BASE" \
  aurora-backend
```

The Flask API listens on port **7860**. Make port 7860 **Public** in the Codespaces Ports tab.

### Frontend

Open a second terminal:

```bash
cd frontend
docker build -t aurora-frontend .
docker run --name frontend --network host aurora-frontend
```

The Streamlit UI listens on port **8501**. Make port 8501 **Public** in the Codespaces Ports tab.

## API endpoints

- `GET /` — health/welcome message
- `POST /v1/relevant_chunks` — returns top-k retrieved chunks
- `POST /v1/answer` — returns generated answer
- `POST /v1/answer_with_relevant_chunks` — returns generated answer plus supporting chunks

## Example query

```text
Is breakfast free at the Miami Brickell property?
```

## Important

Before building the backend image, copy the notebook-generated FAISS files (`index.faiss` and `index.pkl`) into `backend/faiss_index/`.
